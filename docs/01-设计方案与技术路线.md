# reading-quotes 设计方案与技术路线

## 1. 目标

个人读书摘抄站：首页「屏保式」轮播；单用户登录后可增删改；数据保存在仓库内 JSON；腾讯云 clone 后一键部署；变更后自动 `git commit` + `push`。

## 2. 非目标

- 数据库 / 多账号 / 邀请码
- GitHub Actions / CI workflow
- 图片上传、复杂标签体系
- `git push --force`

## 3. 架构

```
浏览器 ──► Vite/React 静态页
              │
              ▼
         Express API（同进程托管 dist）
              │
     ┌────────┴────────┐
     ▼                 ▼
data/quotes.json    git add/commit/push
```

- **前端**：React + React Router + Tailwind（Vite 构建）
- **后端**：Express + Cookie 会话
- **数据**：`data/quotes.json`（文件锁串行写入）
- **鉴权**：`.env` 中单组 `ADMIN_USERNAME` / `ADMIN_PASSWORD`；httpOnly Cookie
- **Git 同步**：每次 CRUD 成功后串行执行；失败保留本地 JSON，后台可重试

## 4. 数据模型

```json
{ "id": "uuid", "content": "...", "author": "...", "book": "...", "year": 2024 }
```

字段均为必填；`year` 为阅读年份（整数）。

## 5. 页面

| 路径 | 说明 |
|------|------|
| `/` | 随机序轮播；60s 自动下一条；左右翻；右上角齿轮进后台 |
| `/admin` | 列表 + 搜索（内容/作者/书名）+ 按年筛选；登录后 CRUD |

## 6. 自动 Git

1. 落盘 JSON  
2. `git add data/quotes.json`  
3. `git commit -m "chore(quotes): add|update|delete <id>"`  
4. `git push` 到 `GIT_BRANCH`（默认 `main`）

使用 `GIT_TOKEN` 注入 https remote。禁止 force。失败时 `GET /api/git/status` 可见，`POST /api/git/retry` 重试。

## 7. 目录要点

- `server/` API 与 Git 同步
- `src/` 前端
- `data/quotes.json` 摘抄数据
- `deploy.sh` 一键部署
- `docs/` 设计与部署文档
- `.env.example` 环境变量模板
