# reading-quotes 部署指导

域名示例：`read.huatuo.cloud`。仓库：`https://github.com/huatuo-dr/reading-quotes`（公开）。

## 1. 服务器准备

- 腾讯云 CVM，建议 Ubuntu 22.04+
- 安装 Node.js 20+、npm、git、Nginx
- 开放 80/443；应用默认监听 `PORT`（建议 3000，仅本机或内网）

## 2. Clone 与配置

```bash
sudo mkdir -p /opt
cd /opt
git clone https://github.com/huatuo-dr/reading-quotes.git
cd reading-quotes
cp .env.example .env
nano .env
```

必填：

| 变量 | 说明 |
|------|------|
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | 后台登录 |
| `SESSION_SECRET` | 长随机串 |
| `GIT_TOKEN` | 有本仓 `contents:write` 的 GitHub PAT（或 fine-grained token） |
| `GIT_ENABLED` | 生产保持 `true` |
| `GIT_BRANCH` | 默认 `main` |
| `PORT` | 默认 `3000` |

可选：`GIT_REMOTE_URL`、`GIT_USER_NAME`、`GIT_USER_EMAIL`。

> 不要把 `.env` 提交进 Git。

## 3. 一键部署

```bash
./deploy.sh
```

脚本会：`npm install` → `npm run build` → 后台启动 `tsx server/index.ts`。

查看日志：

```bash
tail -f logs/app.log
```

## 4. Nginx + HTTPS（`read.huatuo.cloud`）

1. 腾讯云 DNS：`read` CNAME 或 A 记录指向服务器  
2. Nginx 反代示例：

```nginx
server {
  listen 80;
  server_name read.huatuo.cloud;
  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
  }
}
```

3. 用 certbot 或腾讯云证书配置 HTTPS。

本脚本**不**申请证书、不改 DNS。

## 5. 更新代码

```bash
cd /opt/reading-quotes
git pull
./deploy.sh
```

网页增删改会改 `data/quotes.json` 并自动 push；`git pull` 前若有冲突需手工处理（见排障）。

## 6. 排障

| 现象 | 处理 |
|------|------|
| 无法登录 | 检查 `.env` 用户名密码；Cookie 是否被 HTTPS/域名策略拦截 |
| Git 同步失败 | 后台点「重试同步」；检查 `GIT_TOKEN` 权限与分支保护 |
| push 冲突 | SSH 上 `git status` / `git pull --rebase` 后重试同步；避免 force |
| 端口占用 | 改 `PORT` 或结束旧 PID（`logs/app.pid`） |

## 7. 安全提示

服务器持有可写 token；请使用**最小权限** PAT，并保护后台密码。登录被盗意味着仓库可能被改写摘抄文件。
